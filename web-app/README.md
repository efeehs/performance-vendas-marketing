# Aplicação Web

Versão web interativa do dashboard de Performance de Vendas e Marketing.

A aplicação está sendo desenvolvida com Google Apps Script, HTML, CSS e JavaScript, reproduzindo as principais análises apresentadas na versão em Power BI.

## Funcionalidades

- Visão Geral
- Análise de Marketing
- Análise de Vendas e Clientes
- Análise de Produtos e Categorias
- Filtros interativos
- KPIs dinâmicos
- Gráficos interativos
- Tabelas detalhadas

## Status

🚧 Em desenvolvimento.

A estrutura principal da aplicação já está funcional, incluindo carregamento dos dados, filtros, KPIs, gráficos e tabelas. A etapa atual envolve refinamentos, validações e preparação da versão final.
